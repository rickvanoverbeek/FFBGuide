The configuration tool is the only one here that asks the question directly: Damping, Friction, Inertia and Spring each have a dropdown for Device Effect Only, Game Effect Only, or a combination. VRS recommends staying on Device Effect Only.

That makes it a useful reference point for the whole matrix, since it names the distinction other manufacturers bury in their labels. Note that the published documentation states friction and inertia were to be implemented later, so those two are not documented here.
